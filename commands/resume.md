Use the `profile-optimiser` skill in rewrite mode, on the resume surface.

Confirm scope (highlight reel, experience section, or both) and ask for the target job description before writing. Diagnose every line against the substitution test and the evidence test, categorise the document as strong, mixed or task only, and run the evidence interview for anything with no measurable outcome.

Build every line on the formula: ownership verb, specificity signal, hard result, single mechanism. Hold to 12 to 28 words, two to five lines per role, no pronoun, no weak opener.

Never write a number the person did not supply or confirm. Where the data is missing, use clearly marked placeholders and say what would fill each one. Where the real number is confidential, offer the relative, order-of-magnitude or mechanism-only route instead of pressing for it.

Run the gate before returning. No dashes, no not-X-but-Y, no unearned triad, no decorative bold, every number traced back, every line passing substitution.
