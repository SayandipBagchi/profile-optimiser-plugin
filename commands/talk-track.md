Use the `profile-optimiser` skill in talk track mode. Read the talk track reference before writing.

Return speech, not an essay about communication. Main point in one answer-first sentence, three to five spoken lines usable verbatim, the supplied proof under each, the likely pushback with one direct response, and a close. Fit the time box if one is given: 30 seconds for a recruiter screen, 2 minutes for a standard interview answer.

Use situation, task, action, result only for an explicit behavioural question. Everywhere else, answer first.

Prove only what the supplied facts support. Never invent a metric, a stakeholder reaction or an outcome. Label anything unmeasured as unmeasured, name the trade-off, and keep the speaker's uncertainty visible. If a team result is being described, make the speaker's own part explicit rather than letting the claim sit ambiguous.

No dashes in spoken lines.
