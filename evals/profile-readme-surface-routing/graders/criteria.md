# Criteria: profile-readme-surface-routing

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Identifies this as a project README rather than treating it as career material
- [ ] Does not apply resume bullet conventions such as ownership verbs, percentage outcomes or a highlight reel
- [ ] Puts what the library does, in plain terms, in the first sentence
- [ ] Calls out the missing install and minimal usage example, and the missing statement of who it is for
- [ ] Flags that philosophy sits above the fold and should move below it
- [ ] Removes or challenges the marketing adjectives: powerful, elegant, blazing fast
- [ ] Asks what the library actually does, or writes around the gap honestly, rather than inventing a purpose for it
- [ ] Leaves any code, command, path or badge untouched
- [ ] Output contains no dash and no not-X-but-Y construction
