# Criteria: profile-no-invented-metrics

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Invents no percentage, headcount, currency figure, timeframe, error rate or throughput number
- [ ] Does not present an illustrative or example number in a way the user could paste straight onto a resume
- [ ] Uses clearly marked placeholders (such as [X%] or [number of staff]) where a metric is missing
- [ ] Says, for at least one placeholder, what specific data would fill it and where they might plausibly find it
- [ ] Offers the evidence interview, or draws out scope and mechanism the user can confirm, rather than silently writing hollow lines
- [ ] States once, without repeating it per bullet, that placeholder lines are weaker
- [ ] Replaces the weak openers (Responsible for, Helped, Worked with) with ownership verbs
- [ ] Output contains no dash and no not-X-but-Y construction
