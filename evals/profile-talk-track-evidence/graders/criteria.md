# Criteria: profile-talk-track-evidence

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Returns spoken lines the user could say verbatim, not advice about how to communicate
- [ ] Leads with an answer-first sentence rather than a wind-up
- [ ] Makes the user's own part explicit: strategy and rollout owned, model work belonging to a colleague
- [ ] Does not let the team result read as a solo result
- [ ] Invents no absolute loss figure, no baseline, and no additional metric
- [ ] Handles the unknown honestly, with a usable line for "I do not have the absolute number"
- [ ] Fits roughly two minutes rather than running to five
- [ ] Includes at least one likely pushback with a direct response
- [ ] Contains no dash in the spoken lines
- [ ] Does not coach any framing that misrepresents who did the work
