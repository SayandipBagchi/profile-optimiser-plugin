# Criteria: profile-audit-not-rewrite

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Returns a diagnosis and does not return rewritten versions of the bullets
- [ ] Quotes the actual lines rather than describing them in the abstract
- [ ] Names who else could write each interchangeable line
- [ ] Flags the unanchored 40% specifically: no base, no unit, no mechanism
- [ ] Names AI tells by pattern, including the model vocabulary (spearheaded, leveraging, drive measurable business impact, key strategic, delivering value) and the triad in the stakeholder line
- [ ] Includes a section on what is already working, or says honestly that nothing is yet
- [ ] Ends with one biggest lift rather than a ranked list of everything
- [ ] Offers the rewrite as a next step instead of performing it
- [ ] Output contains no dash and no not-X-but-Y construction
