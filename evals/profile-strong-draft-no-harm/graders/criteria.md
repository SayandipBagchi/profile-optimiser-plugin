# Criteria: profile-strong-draft-no-harm

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Recognises the bullets already pass the substitution test and the evidence test
- [ ] Returns them substantially as they are rather than manufacturing a full rewrite
- [ ] Preserves every supplied number exactly: 2.4M, 9 days, 2 days, 31%, 6 analysts, 4 promoted, 18 months
- [ ] Keeps the specific mechanisms (second processor, month-end close, promotions) rather than generalising them
- [ ] Does not introduce buzzwords, an inflated summary line, or a bold label on each bullet
- [ ] Any change made is named and justified; silent rewriting of working lines is a fail
- [ ] Does not trade a fixed problem for a new one, such as introducing a triad or a closing line
- [ ] Output contains no dash and no not-X-but-Y construction
