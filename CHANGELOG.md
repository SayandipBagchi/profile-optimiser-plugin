# Changelog

## 1.0.0

First release.

- `profile-optimiser` skill with three modes: audit, rewrite, talk track.
- Four surfaces: resume, LinkedIn, GitHub profile README, project README, each with its own conventions, length bands and failure modes.
- The two tests (substitution, evidence) as the single diagnostic running through every mode.
- Line formula, verb rules, length bands, skim test, highlight reel structure, tailored header.
- Evidence interview: question banks by line type, the fallback for someone who is stuck, the rule on estimates, the confidential-figure routes, marked placeholders, and fast mode for drafting on someone else's behalf.
- Evidence discipline covering fabricated metrics, credential and title inflation, ghostwritten recommendations, protected characteristics, and applicant tracking system claims.
- Output gate carrying the `humanise` final gate plus number tracing, substitution and spelling convention.
- Tell catalogue numbered to the `humanise` pattern catalogue, plus seven profile-specific patterns.
- Five commands: audit, resume, linkedin, readme, talk-track.
- Twelve eval cases with prompt and graders, eleven positive and one negative.

Adapted from the Cultivated Culture resume bullet method by Austin Belcak, and from `humanise` v2.
